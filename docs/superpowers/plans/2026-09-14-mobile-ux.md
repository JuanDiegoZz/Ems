# Mobile UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make EMS Hospital feel native and usable from 320–430px mobile screens while preserving desktop behavior.

**Architecture:** Keep all domain data and routes unchanged. Add one small presentation-only navigation helper, replace only mobile layouts through CSS/component variants, and preserve desktop tables/sidebar at `md` and above.

**Tech Stack:** Next.js App Router, React 19, TypeScript, Tailwind/CSS, node:test.

**Spec:** User-approved mobile UX design in this conversation.

## Global Constraints

- Do not alter APIs, schema, auth, OCR, clipboard, delivery/shifts/analytics logic, or Discord.
- Mobile navigation is exactly five destinations; desktop sidebar remains unchanged.
- No added dependency or Playwright infrastructure.
- Respect safe-area, reduced motion, 44px targets, and no document horizontal overflow.
